# Parallax landing

Static GitHub Pages site for [Parallax](https://github.com/ClaudiniTokenini/Parallax).

## Publish

1. Create a new GitHub repository (for example `parallax-pages`).
2. Push this folder to `main`.
3. In the repo settings, set GitHub Pages source to `main` / root.

The site will be available at `https://<org-or-user>.github.io/<repo>/`.
